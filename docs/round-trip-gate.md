# The round-trip gate

This is the enforcement of ADR-0002. It is the first thing built in the
repository, on purpose: it turns the round-trip rule from an assumption into a
constraint that the block type catalogue is designed against.

## The rule

The canonical block tree is the single source of truth. Markdown is a
projection of it, used only as an editing surface for people and language
models. The projection must be lossless for the defined profile:

```
from_markdown(to_markdown(tree)) == tree
```

Holding for *the defined profile* is the whole point. There is no lossless
bijection between an arbitrary document tree and Markdown, and none is claimed
(see the addendum to ADR-0002). What the gate guarantees is that everything the
catalogue admits round-trips, and that anything which cannot is kept out of the
catalogue rather than discovered later in a client's document.

## What enforces it

- `tests/strategies.py` generates *canonical* trees: text with no leading or
  trailing whitespace and no internal whitespace runs, built from a deliberately
  hostile alphabet (Markdown metacharacters, German and French punctuation).
  The generator is the machine-readable definition of the profile.
- `tests/test_rundreise.py` asserts the round-trip property over generated
  trees, plus anchored examples: a realistic document with metadata, a paragraph
  full of Markdown metacharacters, and a check that an unsupported construct
  (emphasis) fails loudly instead of being silently dropped.

## Definition of done for a new block type

A block type is not finished when it renders. It is finished when:

1. it is a node in `template_engine.baum` with a serialisable form;
2. it maps both ways in `template_engine.pandoc_ast`, and any construct it cannot
   represent raises rather than dropping content;
3. it is generated by `tests/strategies.py`; and
4. the gate stays green for it.

If a candidate type cannot satisfy (4), it does not enter the catalogue. Row and
column spans in tables are the current example of a construct kept out for this
reason (see the addendum to ADR-0002).

## Running it

```
python -m pip install -e ".[dev]"
pytest -q --hypothesis-show-statistics
```

Pandoc must be on the PATH. The mapping detects its API version at runtime, so
any reasonably recent pandoc works; development used 2.9, CI uses whatever the
runner ships.
